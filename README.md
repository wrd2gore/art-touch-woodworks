## 🚀 Website Features
- **Pure Zero-Dependency Stack**: Built purely with HTML5, CSS3, and Vanilla JavaScript (ES6+).
- **Independent Project Galleries**: Dedicated high-resolution galleries for Banks, Commercial, Residential, Embassies, and Government projects.
- **Interactive Lightbox & Sliders**: Touch-friendly gallery carousel and fullscreen zoom modal.
- **Live Jordan Time Clock**: Real-time workshop open/closed status badge based on Jordan business hours.
- **Quote Request Wizard**: Multi-step woodwork estimate generator.
- **Admin Control Center**: Built-in management app (`admin.html`) to view inquiries and update projects with 1-click persistence.

## 🌐 Publishing to GitHub Pages
1. Go to your repository settings on GitHub (**Settings > Pages**).
2. Under **Build and deployment > Source**, select `Deploy from a branch`.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. Your website will be live across the world in seconds!
